# askFinz indexer node

The askFinz index is read by a fleet of ordinary machines rather than a datacentre. A Windows PC, Raspberry Pi, Mac or Docker host joins with one line, stays capped so it keeps out of your way, and leaves with one line too.

**Website:** [https://askfinz.com](https://askfinz.com) &nbsp;·&nbsp; **Contact:** hello@askfinz.com
